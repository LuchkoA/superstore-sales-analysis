# Superstore Sales Analysis 🛒

Exploratory data analysis of US Superstore retail data (2014–2017).  
**Dataset:** 9,994 orders · 21 features

## Key Findings
- 📈 Revenue grew 51% from $484K (2014) to $733K (2017)
- 🔴 Discounts above 20% generate average loss of -$78 per order
- 🌍 Texas: $170K in sales but -$25K profit
- 📅 Q4 (Sep–Dec) accounts for ~45% of annual revenue

## Tools
`Python` `Pandas` `Matplotlib` `Seaborn`
