# Superstore Sales Analysis

## Overview
Exploratory data analysis of US Superstore retail data (2014–2017).

## Key Findings
- Revenue grew 51% from 2014 to 2017
- Discounts above 20% generate average loss of -$78 per order  
- Texas: $170K sales but -$25K profit — pricing strategy issue
- Q4 (Sep-Dec) accounts for ~45% of annual revenue

## Tools
Python, Pandas, Matplotlib, Seaborn

## Dataset
[Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
